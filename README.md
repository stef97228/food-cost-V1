# FOOD COST V5

Mise à jour locale-first pour GitHub Pages.

## Nouveautés
- Factures fournisseurs : photo/PDF, aperçu, fiche de validation, ajout des prix validés au catalogue.
- Inventaire : quantités par produit et valorisation automatique du stock.
- Produits fournisseurs : ajout manuel et historique local des prix.
- Sous-recettes : rendement désormais possible en g, kg, ml ou L.
- Conservation des clés localStorage existantes pour recettes et sous-recettes.
- Aucun prix fournisseur n'est inventé ou modifié sans validation.

## Important
L'OCR/IA automatique n'est pas encore connecté. Cette version prépare le flux de scan et de validation mais la saisie des lignes de facture reste manuelle.
